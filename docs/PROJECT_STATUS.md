## 🐛 已知问题

1. **依赖扫描不完整**
   - 某些环境的依赖可能无法正确扫描
   - 需要改进错误处理和日志记录

2. **缓存机制需要优化**
   - 当前缓存时间固定为 5 分钟
   - 需要支持用户自定义缓存时间

3. **UI 响应性**
   - 大量环境时列表加载可能较慢
   - 需要实现虚拟滚动优化

4. **跨平台兼容性**
   - Windows 路径处理需要进一步测试
   - Linux 权限问题需要处理
